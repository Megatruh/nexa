2.3 BUG #3: MANAJEMEN WAKTU (TIME MANAGEMENT ISSUES)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Deskripsi:
  - Waktu dihitung berdasarkan TryoutSessionSubtest->started_at
  - MASALAH UMUM yang ditemukan:
    1. Tidak ada mekanisme auto-submit ketika waktu habis
    2. Timer hannya di frontend (JavaScript) - bisa di-bypass dengan DevTools
    3. Toleransi 10 detik terlalu besar untuk anti-cheat
    4. Tidak ada log untuk "expired session"
    5. Jika user refresh saat waktu habis, status subtest tidak otomatis finished

Dampak:
  - User bisa terus menjawab walau waktu sudah habis
  - Tidak ada mekanisme paksa selesai ketika durasi habis
  - Timer frontend bisa dimanipulasi

Solusi:
  1. Tambahkan mekanisme server-side auto-submit:
     ```php
     // Di storeAnswer(), tambahkan pengecekan otomatis:
     if ($terpakai > ($durasiDetik + 10)) {
         // Auto-mark as finished
         $sessionSubtest->update(['finished_at' => now()]);
         
         // Log untuk audit
         \Log::warning('Auto-finish subtest due to time expiry', [
             'session_id' => $session->id,
             'subtest_id' => $question->tryout_subtest_id,
             'time_used' => $terpakai,
             'duration' => $durasiDetik
         ]);
         
         return response()->json(['message' => 'Waktu habis, subtes ditutup.'], 403);
     }
     ```

  2. Kurangi toleransi dari 10 detik menjadi 5 detik atau 2 detik
  
  3. Tambahkan background job (Laravel Queue) untuk auto-submit:
     ```php
     // Create job untuk setiap session_subtest:
     StartAutofinisingJob::dispatch($sessionSubtest)->delay(now()->addMinutes($subtest->duration));
     ```

  4. Tambahkan validasi di showSubtest() untuk subtest yang sudah expired:
     ```php
     if ($sisaWaktu <= 0 && !$sessionSubtest->finished_at) {
         $sessionSubtest->update(['finished_at' => now()]);
     }
     ```

  5. Tambahkan log timestamps lengkap:
     ```php
     protected $fillable = [
         'tryout_session_id',
         'tryout_subtest_id',
         'started_at',
         'finished_at',
         'auto_finished_at'  // Jika auto-submit
     ];
     ```


2.4 BUG #4: TAMPILKAN SESI YANG BELUM SELESAI
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Lokasi: app/Http/Controllers/TryoutController.php (line 24-37)

Deskripsi:
  - Di method index(), HANYA menampilkan sesi yang sudah selesai:
    ```php
    $history = TryoutSession::with('tryout')
        ->where('user_id', $user->id)
        ->whereNotNull('finished_at')  // ← HANYA YANG SELESAI
        ->orderBy('created_at', 'desc')
        ->get();
    ```
  
  - User yang sedang mengerjakan tryout tidak bisa melihat status mereka
  - Tidak ada cara user tahu tryout mana yang belum diselesaikan

Dampak:
  - UX buruk: user lupa di subtest mana mereka terakhir
  - Tidak ada resumption screen yang jelas
  - User mungkin membuat session baru (duplikasi)

Solusi:
  ```php
  public function index()
  {
      $user = Auth::user();

      $activeTryouts = Tryout::where('is_active', true)
          ->withCount('subtests')
          ->get()
          ->map(function ($tryout) {
              $firstSubtest = $tryout->subtests()->orderBy('order', 'asc')->first();
              $tryout->first_subtest_id = $firstSubtest?->id;
              return $tryout;
          });

      // PERBAIKI: Tampilkan SEMUA sesi termasuk yang belum selesai
      $activeSessions = TryoutSession::with('tryout')
          ->where('user_id', $user->id)
          ->whereNull('finished_at')  // Sedang berjalan
          ->orderBy('created_at', 'desc')
          ->get();
      
      // Tentukan subtest mana yang terakhir dibuka
      $activeSessions->each(function ($session) {
          $lastSubtest = TryoutSessionSubtest::where('tryout_session_id', $session->id)
              ->orderBy('created_at', 'desc')
              ->first();
          $session->last_subtest_id = $lastSubtest?->tryout_subtest_id;
          $session->is_completed = count(
              $session->sessionSubtests()->whereNotNull('finished_at')->get()
          );
          $session->total_subtests = count($session->sessionSubtests);
      });

      $history = TryoutSession::with('tryout')
          ->where('user_id', $user->id)
          ->whereNotNull('finished_at')  // Selesai
          ->orderBy('created_at', 'desc')
          ->get();

      return Inertia::render('Tryout/Index', [
          'activeTryouts'   => $activeTryouts,
          'activeSessions'  => $activeSessions,  // TAMBAHKAN INI
          'history'         => $history,
      ]);
  }
  ```
  
  Frontend harus menampilkan "Resume Tryout" button untuk active sessions.
